如何準備特殊選材？

我會把特殊選材的準備分成兩個部分：

「作品與經歷」以及「心態」。

除此之外，還有一個我覺得很重要的部分，就是：

如何主動尋找特選相關的資訊與資源。

一、作品與經歷：不要只是「做很多」，而是要「做對」

準備特殊選材時，我認為第一件事情不是急著做作品，而是先確認：

「我想申請的科系，到底想看到什麼樣的學生？」

1. 作品一定要和申請科系有所連結

不同科系對特殊選材的期待可能差很多，所以可以先去找：

  • 各大學歷年的特殊選材簡章
  • 歷年錄取者的備審資料
  • 學長姐的申請經驗
  • 各校系對特殊選材的要求
  • 網路上的特殊選材心得

從這些資料可以大概整理出：

這個科系希望看到什麼能力？

例如電資相關科系，就可能比較重視：

  • 程式設計
  • 演算法
  • APCS
  • 專題
  • 資訊相關競賽
  • 自主學習
  • 程式作品
  • 研究或小論文

所以與其「什麼活動都參加」，不如把時間集中在和目標科系相關的能力。

二、我很推薦「自學」

如果要我推薦一個很適合特殊選材的經歷，我會很推薦：

自主學習／自學。

原因是自學可以同時證明很多事情：

  • 你對這個領域真的有興趣
  • 你有自主學習能力
  • 你能自己找資料
  • 你能解決遇到的問題
  • 你不是只依賴學校課程
  • 你可以把興趣持續一段時間

而且自學最大的優點之一就是：

不一定需要花很多錢。

自學資源

我自己會把資源分成幾類。

免費：

  • YouTube
  • 官方文件
  • GitHub
  • 網路教學文章

付費：

  • Udemy
  • 其他線上課程

至於 Bilibili，我自己比較不推薦。

不是說上面的內容一定不好，而是我自己使用下來覺得學起來很不舒服，所以不會放在優先選擇。

三、檢定、競賽、專題也可以成為作品的一部分

除了自學之外，也可以依照自己的科系去累積不同的成果。

電資相關

例如：

APCS

APCS 對資訊相關科系來說是一個很值得準備的項目，也有不少學校會把 APCS 成績列為特殊選材或申請上的參考條件。

專題

如果有能力，可以做：

  • 程式專題
  • 網頁
  • App
  • 遊戲
  • AI 專案
  • 硬體專題
  • 自動化工具

重點不是「作品看起來多厲害」，而是你能不能說清楚：

為什麼做？怎麼做？遇到什麼問題？怎麼解決？最後學到了什麼？

小論文／研究

如果對研究有興趣，也可以嘗試：

  • 小論文
  • 科展
  • 專題研究
  • 閱讀論文
  • 自己做實驗
  • 資料分析

四、看到相關活動就可以參加，但不要為了「塞經歷」而參加

高中期間如果看到和目標科系相關的：

  • 營隊
  • 工作坊
  • 講座
  • 競賽
  • 課程
  • 專題活動
  • 實作活動

都可以考慮參加。

但我覺得要注意一件事情：

不是參加越多活動，特殊選材就越有利。

如果你參加十個和科系完全無關的活動，可能還不如一個你真的投入很多時間、最後做出成果的專題。

所以可以把經歷想成一條線：

興趣 → 自學 → 實作 → 作品 → 遇到問題 → 解決問題 → 延伸學習

這樣會比單純堆一大堆證書更有說服力。

五、不要把希望全部放在學校資源

高中學校能提供的資源其實很有限。

所以如果你真的確定自己想走某個方向，我會建議：

主動去找外部資源。

例如：

  • YouTube
  • 線上課程
  • GitHub
  • Discord 社群
  • 學長姐
  • 大學教授／研究室公開資訊
  • 各大學系所網站
  • 網路文章
  • 書籍

特殊選材本身就在看你的自主性。

所以：

自己找到資源 → 自己學 → 自己做

本身其實就是一個很好的學習歷程。

六、特殊選材其實很需要「情報蒐集」

這是我覺得很多人容易忽略的部分。

你不只是要準備作品，也要知道：

「其他人是怎麼準備的？」

我自己推薦幾個找資料的地方。

1. Discord 特殊選材群組

可以找到：

  • 特殊選材討論
  • 交叉放榜
  • 備審資料交換
  • 申請經驗
  • 學校資訊

尤其是交叉放榜很有參考價值，可以觀察不同學校、不同科系最後錄取的人的背景。

2. Threads

Threads 上面其實有不少高中生會分享：

  • 特殊選材經驗
  • 備審
  • 面試
  • 錄取結果
  • 各校心得

如果看到和自己目標科系相關的人，也可以禮貌地私訊詢問。

3. 104 學習歷程

104 學習歷程上也有人會分享自己的：

  • 學習歷程
  • 備審
  • 申請經驗
  • 作品

可以拿來觀察別人的呈現方式。

4. 學長姐歷年的備審

這個我非常推薦。

如果可以找到同校、同科系，甚至是同一個特殊選材管道的學長姐，價值會很高。

可以直接詢問：

「你當初準備特殊選材的時候，最重要的作品是什麼？」

「教授面試最常問什麼？」

「如果重新準備一次，你會提早做什麼？」

這些答案通常比自己一直猜有用很多。

5. YouTube：47 雲端輔導室

可以拿來了解：

  • 特殊選材
  • 備審
  • 面試
  • 學習歷程
  • 自傳
  • 申請策略

不過建議把 YouTube 當成建立觀念的工具，不要完全照著別人的模板複製。

6. 各大學的備審指引

這個其實非常重要。

直接去找目標大學／科系提供的：

  • 特殊選材簡章
  • 備審準備指引
  • 面試準備資訊
  • 評分標準
  • 歷年資料

因為最後真正決定你能不能進去的，還是那個學校與科系自己的規則。

七、最後可以把整個特殊選材準備濃縮成這張圖

① 先決定目標科系

↓

② 研究歷年簡章與錄取者

↓

③ 找出科系需要的能力

↓

④ 開始自學

↓

⑤ 做專題／作品／參加相關活動

↓

⑥ 累積成果與反思

↓

⑦ 找學長姐、Discord、Threads 等蒐集情報

↓

⑧ 整理備審

↓

⑨ 準備面試

↓

⑩ 保持自信，但不要預設自己一定會上

準備備審資料的 Tips

1. 自傳，是拉開你和競爭對手差距的地方

自傳不要只是「介紹自己」，而是要讓教授知道你是誰、你做過什麼，以及你為什麼走到今天。

經歷可能會重複，但每個人的故事、選擇與思考不一樣。
自傳，就是把這個「不一樣」說出來。

2. 把重要經歷放在前面

我習慣在前面的 Page 就先把自己的重要經歷、專案、競賽、活動整理出來。

讓教授一開始就能快速知道：

「這個人做過什麼？」

後面再用篇幅補充細節。

3. 每篇文章先講重點

我習慣在每篇文章最前面，用一個小標題或一句話先告訴教授：

「這篇要講什麼？」

教授閱讀備審的時間有限，不要讓教授自己找重點。

先講結論，再用內容證明。

4. 專案一定要留下紀錄

高一、高二開始做專案時，就建議建立一個簡單的紀錄 Page。

不用漂亮，先把素材留下來：

  • 時間
  • 地點
  • 專案原理
  • 製作過程
  • 遇到的問題
  • 解決方法
  • 成果
  • 收穫
  • 心得與反思
  • 照片

尤其是照片，一定要留。

5. 高一、高二先記錄，高三再美化

這是我覺得最重要的一點。

高一、高二做的東西，到了高三回頭看，覺得很醜、很粗糙非常正常。

所以前期不要花太多時間在排版和美化。

先留下素材，再整理成作品。

高三可以重新設計，但如果當初沒有留下照片、過程和細節，之後想補就很困難。

備審最怕的不是以前做得醜，而是你忘記自己以前做過什麼。
